SitRep

A trading alert in, a short situation report out, in a few seconds.

When an alert fires on a chart, SitRep pulls two live numbers from Binance: how today's volume compares with its 20-day average, and how far price sits from its 20-day moving average. Claude turns them into a short, structured report, which goes to Telegram.

It describes the context around a signal you defined. It never says buy, sell, or where price is going.

Try it

Each run uses live market data. Demo runs send nothing to Telegram.

Result

SitRep reports context, never advice. Source on GitHub
